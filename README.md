# morflights

Tracks cheap direct and connecting flights from Morocco to destinations that
are visa-free, visa-on-arrival, or easy e-visa for Moroccan passport holders
— plus Turkey and Saudi Arabia, tracked unconditionally. Sends a push
notification to your iPhone whenever a route hits a new low price.

Everything here is free: free flight-price API tier, free push notifications
(ntfy.sh), and free hosting (your own Docker, and/or GitHub Actions).

## How it works

- `app/data/visa_free_destinations.json` — the destination list (country,
  visa category, main airports). Starter list generated by AI research —
  **verify visa rules yourself before booking**, they change.
- `app/src/travelpayouts_client.py` — fetches cheapest current fares
  (direct + connecting) per route from the Travelpayouts Data API.
- `app/src/main.py` — for every origin x destination airport pair, checks
  the cheapest fare; if it's a new low (or at least `IMPROVEMENT_THRESHOLD_PCT`
  cheaper than the last alert) and under `MAX_PRICE_USD`, sends a push alert.
- `app/src/storage.py` — SQLite file remembering best price per route, so
  you're not re-alerted on the same price every run.
- `app/src/notifier.py` — sends the alert via [ntfy.sh](https://ntfy.sh).
- `app/src/scheduler.py` — loops `main.py` on an interval, for the Docker
  container.
- `.github/workflows/check-flights.yml` — same check, run for free on
  GitHub's cloud cron (in case your machine is off).

## Important: connecting flights and Schengen/UK transit visas

If you're a Moroccan passport holder **without a Schengen (or UK) visa**,
connecting through most European hub airports (Paris, Madrid, Lisbon,
Brussels, Milan, etc.) requires an Airport Transit Visa even if you never
leave the airport. The free flight-price API this app uses **does not
report the actual layover airport** — only the airline and stop count.

To stay safe, `app/data/safe_transit_airlines.json` allowlists airlines
whose hub is confirmed outside the Schengen Area/UK (Turkish Airlines,
Gulf carriers, EgyptAir, Royal Air Maroc, etc.). `app/src/main.py` only
considers a connecting itinerary if it's flown by one of those airlines;
anything else is silently dropped unless it's a direct flight. This is a
heuristic, not a guarantee — **always check the actual routing on the
booking page before paying**, and every connecting-flight alert includes
a reminder to do so.

## One-time setup (~5 minutes)

### 1. Get a free Travelpayouts API token

1. Go to https://www.travelpayouts.com and sign up (free, no card).
2. In your dashboard, open **Tools -> API tokens** (or **Access to API**)
   and create a token.
3. Keep it handy for step 3.

### 2. Install ntfy on your iPhone

1. Install **ntfy** from the App Store (free, no account needed).
2. In the app, tap **+** and subscribe to a topic name of your choosing —
   pick something private and hard to guess, e.g. `morflights-<random-8-chars>`.
   Anyone who knows your topic name can see your alerts, so don't use
   something guessable like `morflights-morocco`.

### 3. Configure

```
cp .env.example .env
```

Edit `.env`:
- `TRAVELPAYOUTS_TOKEN` — from step 1
- `NTFY_TOPIC` — the topic you subscribed to in step 2
- `ORIGIN_AIRPORTS` — defaults to `CMN,RBA,RAK,TNG` (Casablanca, Rabat,
  Marrakesh, Tangier)
- `MAX_PRICE_USD`, `MAX_STOPS`, `IMPROVEMENT_THRESHOLD_PCT` — tune to taste

### 4. Run it — pick one or both

**Locally with Docker (recommended, since you already run Docker 24/7):**

```
docker compose up -d --build
```

Runs forever in the background, rechecking every `CHECK_INTERVAL_SECONDS`
(default 6h). Logs: `docker compose logs -f`.

**Free cloud backup with GitHub Actions:**

1. Push this repo to GitHub (see below).
2. In the repo's **Settings -> Secrets and variables -> Actions**:
   - Add secrets: `TRAVELPAYOUTS_TOKEN`, `NTFY_TOPIC`
   - Add variables (optional, same names as `.env`): `ORIGIN_AIRPORTS`,
     `CURRENCY`, `MAX_PRICE_USD`, `MAX_STOPS`, `IMPROVEMENT_THRESHOLD_PCT`
3. The workflow runs automatically every 6 hours, and can be triggered
   manually from the **Actions** tab (**Run workflow**).

## Pushing this to GitHub

No GitHub CLI was available in this environment, so create the repo
yourself:

```
git remote add origin https://github.com/<your-username>/morflights.git
git branch -M main
git push -u origin main
```

## Editing the destination list

`app/data/visa_free_destinations.json` is plain JSON — add, remove, or
correct entries freely. Each entry: `country`, `iso2`, `airports` (up to 3
IATA codes), `visa_category` (`visa_free` / `visa_on_arrival` / `e_visa_easy`),
`max_stay_days`, `notes`.
